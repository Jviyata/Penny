# Scene photos

Drop warm lifestyle photos here and each screen picks them up automatically:

- `home.jpg` (or .webp/.png) — Home (e.g. a smoothie on a sunny table)
- `free.jpg` — Free spending (e.g. flowers)
- `chat.jpg` — Can I afford this? (e.g. pastries, a café table)
- `shelf.jpg` — The Shelf
- `goals.jpg` — Goals

Portrait, about 1200×2600, JPEG under ~400 KB each. Until a file exists, a warm gradient stands in. Restart the dev server (or redeploy) after adding one.
